# Double Cross Connect

A 3×3 word puzzle PWA. Swap tiles to find the shared connection across every row and column; solved lines lock into place. The About page includes a QR code for sharing the game.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm test
npm run build
```

## GitHub Pages

The site is deployed from GitHub Actions at https://newspire.github.io/double-cross-connect/. The workflow runs on pushes to `main` and `newspire-double-cross-connect`.

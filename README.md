# Double Cross Connect

A 3×3 word puzzle PWA. Swap tiles so every row and column matches a category; any category can appear horizontally or vertically, and solved lines lock into place. The About page includes a QR code for sharing the game.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm test
npm run build
```

## GitHub Pages

The site is deployed from GitHub Actions at https://newspire.github.io/double-cross-connect/. The workflow runs on pushes to `main` and `newspire-double-cross-connect`.
